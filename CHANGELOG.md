# qLibs Changelog

## 1.0.0+mc1.21.1

### Features
- **qCore** — Platform abstraction, tick-based scheduler, logging
- **qConfig** — Config builder with file persistence
- **qNet** — Packet networking with custom payload support
- **qRender** — HUD overlays, GUI widgets (QPanel, QLabel, QProgressBar), particle helpers
- **qData** — Player data storage (SavedData-backed), JSON utilities
- **qWorld** — Cross-dimensional teleport helpers, value noise, spawn utilities
- **qInventory** — Item builder, menu slot layout helpers
- **qMath** — Vector math, easing functions
- **qCompat** — Soft mod-loaded detection stubs

### Waybound
- Example mod extracted to standalone repository: `https://github.com/qloak/Waybound`
- Compatible with Fabric and NeoForge
